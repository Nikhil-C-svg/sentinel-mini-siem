# Validation — placement edition

Validated locally on Python 3.14.6, Streamlit 1.67.0 and pandas 3.1.1.

- 28 pytest checks passed, including empty and populated dashboards, settings persistence,
  investigation status and notes, cross-file overlap, late arrivals, host isolation,
  evidence-driven reopening, schema migration, rollback and CSV neutralization.
- All nine designed synthetic scenarios matched their expected rule sets.
- Scenario-rule precision/recall: 1.0 / 1.0 on this designed dataset only.
- Benign batch: 10,000 events in 0.695 seconds.
- Dense failure batch: 10,000 events in 4.1918 seconds,
  grouped into one incident with all 10,000 evidence IDs.
- Results were generated by python evaluate.py --benchmark 10000.
- The GitHub Actions workflow is included but has not been run on GitHub.

The isolated execution environment lacked USERPROFILE; supplying the actual Windows user profile
allowed Streamlit configuration loading. Normal Windows terminals ordinarily provide it.

These checks do not establish production security, real-world detection accuracy or distributed scalability.
See reports/evaluation.json for timing scope and environment.
